# Блог из Obsidian

Это хранилище `sinc`. Заметки находятся в корне и папке `projects/`; движок Quartz и оформление — в скрытой папке `.site/`.

Плагин Git автоматически коммитит и отправляет изменения каждые 5 минут, получает изменения каждые 10 минут и при открытии Obsidian. Плагин работает, пока открыт Obsidian. Для ручной отправки: палитра команд → Git: Commit-and-sync. Ветка `main` связана с `origin/main`.

Каждая отправка в `main` запускает GitHub Actions и обновляет https://sofya0206.github.io/blog-obs/ . Markdown-файл с `draft: true` в YAML не попадает на сайт. `.obsidian/`, `.trash/`, `.env` и локальные файлы конфигурации исключены из Git.

Все обычные заметки и поддерживаемые вложения из этого хранилища входят в сайт. Служебный README исключён. Добавляй страницы с понятным названием и внутренними ссылками `[[Название]]`.

Для проверки сборки:

```sh
cd .site
npm ci
npm run build
```
