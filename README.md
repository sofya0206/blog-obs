# Личный Obsidian и блог

Основное хранилище: `sinc`. «Главная» — начало работы; обычные новые записи сохраняются в «Заметки», дневные — в «Дневник», картинки и файлы — во «Вложения».

Заметки используют обычный Markdown и ссылки `[[Название]]`, без HTML. Шаблоны встроенного плагина находятся в «Шаблоны»: ⌘⌥T вставляет шаблон, ⌘⇧D открывает дневную запись с готовым шаблоном.

Git отправляет изменения каждые 5 минут, пока открыт Obsidian. Все обычные заметки и вложения публикуются на https://sofya0206.github.io/blog-obs/ после успешной сборки. Шаблоны, этот README, настройки Obsidian и скрытые служебные файлы исключены из сайта. Они не являются страницами блога. Репозиторий публичный.

Движок и оформление хранятся в скрытой папке `.site`; цвета и структура блога сохранены. Для локальной сборки: `cd .site` и `npm run build`.

Для живого предпросмотра запусти `npm --prefix .site run dev` из папки `sinc` и открой http://127.0.0.1:8091/blog-obs/. Сохраняй заметки в Obsidian — текст, новые файлы, переименования, ссылки и вложения попадут в предпросмотр автоматически; браузер обновится после пересборки. Названия обычных страниц следуют именам заметок, а имя и направления на главной задаются в свойствах «Главная».

Локальные изменения видны через несколько секунд. Публичный сайт обновляется после отправки Git и успешной сборки GitHub Pages.
