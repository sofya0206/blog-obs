**Формат:** локальный инструмент на Python.

Бот принимает голосовые сообщения, видеокружочки, аудио и видео и возвращает текст. Распознавание выполняется локально через Whisper, без отправки записи в облачный сервис распознавания.

## Задача

Сделать голосовые сообщения удобнее для чтения, поиска и дальнейшей работы с текстом.

## Реализация

Python, Telegram Bot API и faster-whisper. Для работы нужен запущенный процесс на компьютере.

Это описание реализации; текущая доступность бота здесь не заявляется.
