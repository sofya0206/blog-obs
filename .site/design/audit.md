# Проверка интерфейса — 1 октября 2026

Сохранена структура Quartz и тема OFF+BRAND. Проверены текущие шесть заметок, два списка разделов и страница 404.

| Проблема | Исправление |
| --- | --- |
| Текст ссылок «Последних заметок» исчезал при наведении | Цвет текста и фон состояния задаются общей парой; устранён конфликт специфичности |
| Даты были слишком бледными | Убрана дополнительная прозрачность из компонентов списков; используется контрастный вторичный цвет |
| Кнопки, поля и состояния различались | Выделены общие токены, классы UI и компонент кнопки с иконкой |
| Поиск и граф не удерживали фокус | Общий диалог: Tab внутри, Escape, явное закрытие, возврат фокуса, недоступный фон |
| Предпросмотры работали нестабильно | Исправлены кэш и ссылки на заголовки; добавлены клавиатура, Escape и переход указателя внутрь |
| Мобильные состояния конфликтовали | Закрытие меню при переходе и Escape, кнопки 44px, сенсорная прокрутка рядом с графом |
| Печать тёмной темы давала нечитаемый код | Отдельные светлые токены печати |

## Проверки

- Сборка Quartz, TypeScript и `git diff --check` прошли.
- 9 маршрутов × 2 темы × 2 размера (390/1440px): 36 вариантов. Проверены ссылки и кнопки при наведении, контраст видимого текста, переполнение, ошибки JavaScript и загрузки.
- На ширинах 320, 390, 768, 844 и 1440px проверены поиск, клавиатура, граф, мобильное меню и режим чтения. Для графа проверена сенсорная прокрутка через Chromium CDP.
- Дополнительно проверены предпросмотры мышью и клавиатурой, повторное открытие ссылки на заголовок, печать из тёмной темы.
- После исправления дат повторно проверены главная, раздел заметок и весь каталог компонентов в двух темах на 390/1440px. Расчёт контраста учитывает прозрачность предков.

Каталог `ui-kit.html` использует тот же скомпилированный CSS, что сайт. Тесты выполнены в Chromium с мобильной эмуляцией; Safari и физические устройства в эту проверку не входили. Это проверка перечисленных сценариев, не сертификация доступности.

Основания для состояний: [контраст текста](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [модальные диалоги](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/), [контент при наведении и фокусе](https://www.w3.org/WAI/WCAG22/Understanding/content-on-hover-or-focus.html).
