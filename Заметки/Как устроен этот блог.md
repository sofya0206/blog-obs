Этот блог устроен как сеть заметок. Начать можно с [[Зачем вести заметки|заметки о том, зачем их вести]], а дальше переходить по ссылкам между мыслями.

## Как это работает

Каждая страница — обычный файл Markdown в моём Obsidian. Папки становятся разделами в проводнике слева, ссылки между страницами — линиями в графе справа. Новые записи из Obsidian появляются на сайте после синхронизации с GitHub.

**Дневник** пока пустой: позже здесь появятся короткие наблюдения. **Проекты** — место для будущих кейсов по арт-дирекшну. Сейчас я собираю язык, темы и свой взгляд в заметках.

## Что можно делать здесь

- Открывать страницы через разделы слева.
- Переходить по ссылкам и смотреть связи в графе.
- Искать заметки по всему блогу через кнопку поиска или `⌘K`.
